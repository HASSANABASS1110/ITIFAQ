# اتفاق — النسخة الكاملة

منصة "اتفاق" بتربط الميديا باير بعملائه: كل عميل ليه لينك بريف خاص بيه،
يملاه من غير حساب، وإجاباته بتوصلك مرتبة في لوحة تحكم واحدة مع إشعار فوري.

الحزمة دي فيها كل حاجة: الموقع + قاعدة البيانات + خطوات التشغيل من الصفر،
من غير أي خبرة برمجة. كل الخدمات المستخدمة مجانية.

---

## اللي هنعمله (ربع ساعة بالظبط تقريباً)

1. نعمل حساب Supabase (ده اللي هيخزّن البيانات) — مجاني.
2. نشغّل قاعدة البيانات (نسخ ولصق ملف واحد جاهز).
3. نحط مفتاحين في ملف واحد.
4. نرفع الكود على GitHub.
5. نوصله باستضافة مجانية (Cloudflare Pages أو Vercel).

---

## الخطوة ١: حساب Supabase

1. افتح supabase.com واضغط **Start your project**.
2. سجّل بحساب GitHub بتاعك (أسهل)، أو بالإيميل.
3. بعد ما تدخل، اضغط **New project**:
   - **Name**: اكتب `itifaq`
   - **Database Password**: اختار كلمة سر قوية و**احفظها عندك** (مش هتحتاجها
     في الموقع، بس ممكن تحتاجها لو دخلت قاعدة البيانات بعدين).
   - **Region**: اختار أقرب منطقة (مثلاً Frankfurt أو أي حاجة).
4. اضغط **Create new project** واستنى دقيقتين لحد ما يجهز.

## الخطوة ٢: تشغيل قاعدة البيانات

1. من القايمة اللي على الشمال في Supabase اضغط على **SQL Editor**
   (أيقونتها زي `>_`).
2. اضغط **New query**.
3. افتح ملف `schema.sql` اللي جوه الحزمة دي بأي برنامج نصوص (حتى Notepad)،
   **انسخ كل اللي فيه** والصقه في المربع الكبير.
4. اضغط **Run** (أو Ctrl+Enter).
5. لو ظهرت رسالة خضرا "Success" يبقى تمام ✅. لو ظهر error، انسخه وابعتهولي.

> الملف ده بيعمل: الجداول، صلاحيات الحماية (كل ميديا باير يشوف عملاءه بس)،
> دوال لينكات العملاء، وتخزين الملفات.

## الخطوة ٣: تأكيد الإيميل (مهم)

**سيب تأكيد الإيميل شغال زي ما هو — متقفلوش.** ده اللي بيمنع أي حد يعمل حساب
بإيميل مش بتاعه، ولازم يفضل شغال طالما فيه بيانات عملاء حقيقية.

(للتجربة الأولى بس، لو حابب تدخل بسرعة من غير ما تفتح إيميلك: ممكن **مؤقتاً**
تقفل **Confirm email** من Authentication ← Sign In / Providers ← Email ←
**Save**، تجرب، وبعدين **ترجّعه شغال تاني قبل ما تبعت لينكات لعملاء حقيقيين**.)

أول مرة تعمل حساب في الموقع، هيوصلك إيميل تأكيد من Supabase — افتحه واضغط
اللينك اللي فيه، وبعدين سجّل دخولك عادي.

## الخطوة ٤: المفتاحين

1. من القايمة الشمال: **Project Settings** (ترس ⚙ تحت) ← **API**.
2. هتلاقي:
   - **Project URL** — شكله `https://xxxxx.supabase.co`
   - **anon** `public` key — نص طويل
3. افتح ملف `config.js` اللي جوه الحزمة (بأي برنامج نصوص) وحط القيمتين
   مكان الكلام الإنجليزي، بين العلامتين `" "`، واحفظ الملف.

> متخفش: المفتاح ده (anon public) معمول يتشاف عادي، والحماية الحقيقية
> شغالة من قاعدة البيانات نفسها (اللي عملناها في الخطوة ٢).

## الخطوة ٥: الرفع على GitHub

1. افتح github.com وادخل بحسابك، اضغط **+** ← **New repository**.
2. الاسم: `itifaq` ← **Create repository**.
3. اضغط اللينك **uploading an existing file**.
4. اسحب **كل ملفات الحزمة دي** (index.html و style.css و app.js و config.js
   و schema.sql و README.md و _redirects و vercel.json ومجلد fonts كله).
5. **Commit changes**.

## الخطوة ٦: الاستضافة المجانية

### على Cloudflare Pages:

1. pages.cloudflare.com ← **Create a project** ← **Connect to Git**.
2. وصّل حساب GitHub واختار ريبو `itifaq` ← **Begin setup**.
3. **Framework preset**: None
4. **Build command**: فاضية (امسح أي حاجة)
5. **Build output directory**: اكتب `/`
6. **Save and Deploy** ← استنى دقيقة ← الموقع شغال على `itifaq.pages.dev`.

### أو على Vercel:

1. vercel.com ← **Sign Up** بحساب GitHub.
2. **Add New…** ← **Project** ← **Import** جنب ريبو `itifaq`.
3. متغيرش حاجة ← **Deploy** ← الموقع شغال على `itifaq.vercel.app`.

> ملفات `_redirects` و `vercel.json` الموجودة في الحزمة بتخلي لينكات
> العملاء (`/b/xxxx`) تشتغل صح في الاتنين، مش محتاج تعمل فيها حاجة.

## جرب إن كل حاجة شغالة

1. افتح لينك موقعك ← **ابدأ مجاناً** ← اعمل حساب بإيميلك ← أكد الإيميل
   من الرسالة اللي هتوصلك ← سجّل دخولك.
2. من لوحة التحكم: **بريف جديد** ← اكتب اسم عميل تجريبي ← هيطلعلك لينك.
3. افتح اللينك في متصفح تاني (أو من الموبايل) واملاه للآخر.
4. ارجع للوحة التحكم: هتلاقي إشعار وصل 🔔 والبريف ظهر مكتمل.

## لو عدّلت حاجة في الكود بعدين

عدّل الملف على GitHub (علامة القلم) ← Commit changes ← الاستضافة
هتحدّث الموقع لوحدها خلال دقيقة.

## اللي جوه الحزمة

| الملف | وظيفته |
| --- | --- |
| `index.html` | صفحة الموقع |
| `style.css` | التصميم |
| `app.js` | منطق الموقع كله |
| `config.js` | مفتاحي الاتصال بـ Supabase (الخطوة ٤) |
| `schema.sql` | إعداد قاعدة البيانات (الخطوة ٢) |
| `_redirects` / `vercel.json` | تشغيل اللينكات على الاستضافة |
| `fonts/` | خط Tajawal والإيموجي |
| `README.md` | الملف اللي إنت بتقراه ده |

## ملاحظات

- الخطة المجانية في Supabase كفاية جداً للبداية (٥٠٠ ميجا قاعدة بيانات
  وجيجا تخزين ملفات). لو المشروع كبر، الترقية بـ ٢٥ دولار في الشهر.
- الإشعارات دلوقتي جوه الموقع (الجرس في لوحة التحكم وبيتحدّث لحظياً).
  إشعارات الإيميل خطوة جاية محتاجة خدمة إيميلات خارجية.
- الملفات اللي العميل بيرفعها بتتخزن على Supabase Storage في **مخزن خاص**
  (مش عام): اللي يقدر يفتح الملف هو العميل صاحب اللينك أو الميديا باير صاحب
  الحساب بس، واللينكات بتتولّد بتوقيع مؤقت (صلاحيتها ١٠ دقايق). ولو مسحت عميل،
  ملفاته بتتمسح معاه ووصول لينكه لأي حاجة بيقف فوراً.
- تقدر تمسح أي عميل بكل بياناته من صفحته (زرار 🗑 مسح العميل).

محتاج مساعدة؟ ابعتلي سكرين شوت من اللي ظهرلك وهقولك تعمل إيه.
